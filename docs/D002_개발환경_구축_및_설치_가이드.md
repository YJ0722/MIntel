# D002. 개발환경 구축 및 설치 가이드

## 1. 대상 환경

- **하드웨어**: Apple Silicon Mac (M3 Pro, 18GB Unified Memory 기준으로 검증됨)
  - Intel Mac이나 다른 OS에서도 동작은 하지만, MPS(Metal Performance Shaders) 가속은
  사용할 수 없고 CPU로 자동 폴백합니다 (관련 코드: `ClipEmbedder._select_device()`,
  `ObjectDetector._select_device()`).
- **Python**: 3.10.x (개발 시 검증 버전: 3.10.20)
- **패키지 관리**: conda (가상환경 이름: `mintel`)

## 2. 사전 준비물

### 2.1 Miniforge/conda 설치

Apple Silicon 환경에서는 Miniforge 사용을 권장합니다.

```bash
brew install miniforge
```

### 2.2 Ollama 설치 (로컬 LLM/VLM 런타임)

3번 방(Inference Layer)이 사용하는 Llama-3, LLaVA는 파이썬 패키지가 아니라
**별도의 로컬 서버(Ollama)** 위에서 구동됩니다.

```bash
brew install ollama
```



## 3. 설치 절차



### 3.1 conda 가상환경 생성 및 활성화

```bash
conda create -n mintel python=3.10 -y
conda activate mintel
```



### 3.2 파이썬 의존성 설치

프로젝트 루트의 `requirements.txt`를 사용합니다.

```bash
(mintel) $ pip install -r requirements.txt
```

`requirements.txt`에 포함된 주요 패키지와 역할은 다음과 같습니다.


| 패키지             | 역할                              | 사용 위치                                                       |
| --------------- | ------------------------------- | ----------------------------------------------------------- |
| `opencv-python` | 영상 읽기, Key-frame 추출(히스토그램 비교)   | `modules/ingestion/keyframe_extractor.py`                   |
| `torch`         | 딥러닝 백엔드 (Apple Silicon은 MPS 가속) | `clip_embedder.py`, `object_detector.py`                    |
| `transformers`  | CLIP 모델(이미지/텍스트 임베딩) 로드         | `modules/ingestion/clip_embedder.py`                        |
| `ultralytics`   | YOLOv8 객체 탐지                    | `modules/ingestion/object_detector.py`                      |
| `easyocr`       | 프레임 내 텍스트(OCR) 인식               | `modules/ingestion/text_recognizer.py`                      |
| `qdrant-client` | 로컬 파일 기반 벡터 DB                  | `modules/storage/qdrant_client.py`                          |
| `ollama`        | 로컬 Ollama 서버와 통신하는 클라이언트        | `modules/inference/llava_analyzer.py`, `llama_responder.py` |


> `torch`는 Apple Silicon용 MPS 백엔드를 지원하는 공식 배포판이 설치되므로 별도의
> CUDA 설정은 필요하지 않습니다.



### 3.3 Ollama 서버 구동 및 모델 pull

```bash
# 서버 실행 (macOS 앱으로 실행해도 무방)
ollama serve

# 별도 터미널에서 필요한 모델을 미리 받아둡니다
ollama pull llama3
ollama pull llava
```

- `llama3`: 3번 방에서 최종 한국어 답변을 생성하는 텍스트 전용 LLM
- `llava`: 3번 방에서 후보 프레임이 실제로 질문에 해당하는지 검증하는 비전-언어 모델
- 두 모델 모두 Ollama Hub의 **기본 태그**를 사용하며, 기본 태그는 Q4_0(4-bit) 양자화
GGUF로 배포되어 M3 Pro 18GB 환경에서도 안전하게 순차 로드/언로드하며 구동됩니다.



### 3.4 YOLOv8 / CLIP 가중치 다운로드

별도 설치 명령이 필요 없습니다. 아래 두 모델은 **최초 실행 시 자동으로 다운로드**됩니다.

- `yolov8n.pt` (YOLOv8 nano, ultralytics가 프로젝트 루트에 자동 저장)
- `openai/clip-vit-base-patch32` (Hugging Face Hub, `~/.cache/huggingface/`에 캐시)

> Hugging Face Hub 접속이 일시적으로 불안정한 경우(504 등) 재시도 로그가 나올 수
> 있습니다. 캐시가 이미 있다면 `CLIPProcessor.from_pretrained(..., local_files_only=True)`
> 형태로 오프라인 로드하도록 임시 전환할 수 있습니다.



## 4. 설치 확인

```bash
(mintel) $ python -c "import cv2, torch, transformers, ultralytics, easyocr, qdrant_client, ollama; print('OK')"
```

`OK`가 출력되면 파이썬 의존성 설치는 정상입니다. 이어서 Ollama 연결까지 확인하려면:

```bash
(mintel) $ python pipeline_inference.py "연결 테스트"
```

Qdrant DB에 아직 데이터가 없다면 "후보 장면을 찾지 못했습니다" 응답이 정상이며,
이는 설치 자체가 잘못된 것이 아니라 2번 방(Storage)까지 데이터가 적재되지 않았기
때문입니다. 전체 파이프라인을 처음부터 실행하는 방법은
[D004. 실행 및 테스트 방법](./D004_실행_및_테스트_방법.md)을 참고하세요.

## 5. 자주 발생하는 문제


| 증상                                           | 원인                               | 해결                                                                                                     |
| -------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `ollama.chat` 호출 시 연결 오류                     | Ollama 서버 미실행                    | `ollama serve` 또는 macOS Ollama 앱 실행                                                                    |
| YOLO/CLIP 다운로드 시 `HTTP Error 504` 반복         | Hugging Face Hub 일시 장애           | 잠시 후 재시도, 또는 이미 캐시된 경우 오프라인 로드로 전환                                                                     |
| `torch.backends.mps.is_available()`가 `False` | Apple Silicon이 아니거나 구버전 torch    | CPU로 자동 폴백되어 느리지만 동작은 함                                                                                |
| `qdrant_client.py`를 직접 실행 시 `ImportError`    | 파일명이 실제 `qdrant_client` 패키지명과 동일 | `python modules/storage/qdrant_client.py`처럼 직접 실행하지 말고, `pipeline_storage.py`/`app.py`를 통해 import해서 사용 |

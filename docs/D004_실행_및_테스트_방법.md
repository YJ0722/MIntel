# D004. 실행 및 테스트 방법

> **상태: 작성 예정 (Draft 전)**
> 이 문서는 성능 측정(각 단계별 처리 시간, 리소스 사용량) 결과가 나온 뒤,
> 그 수치를 반영해 완성할 예정입니다. 지금은 목차와 임시 실행법만 기록해둡니다.

## 임시 실행법 (기본 동작 확인용)

전체 파이프라인(ingestion 단계 -> storage 단계 -> inference 단계)을 한 번에 실행합니다.

```bash
conda activate mintel
python app.py
```

특정 단계만 개별적으로 실행하고 싶을 때:

```bash
# ingestion 단계만 실행 (영상 -> Key-frame 추출/가공)
python pipeline_ingestion.py

# storage 단계를 실행하고 현재 Qdrant 적재 개수 확인
python pipeline_storage.py

# inference 단계만 실행 (커맨드라인 인자로 질문 전달 가능)
python pipeline_inference.py "차가 보이는 장면을 찾아줘"
```

## 완성 시 포함될 내용 (예정)

- [ ] 메모리 사용량 측정 결과 (M3 Pro 18GB 환경, 단계별 peak RAM)
